# BuckyOSApp E2E 验证需求

## 1. 范围

本文档定义 BuckyOSApp 在 Android、Windows 和 macOS 上需要验证的完整用户路径。

OOD、SN、BNS 作为 BuckyOSApp 用户流程的依赖，只验证用户通过 App 能否完成目标，以及最终状态能否正确显示和恢复。

## 2. 优先级

| 优先级 | 使用频次 | 验证范围 |
| --- | --- | --- |
| P0 | 高频 | 启动 App、查看当前身份和 OOD 状态、使用当前身份完成授权 |
| P1 | 中频 | 切换身份、查看应用、调整设置、发现和访问 OOD |
| P2 | 低频 | 创建、导入、备份、删除账户，绑定、解绑 OOD，安装和升级 |

以下低频路径涉及账户恢复、数据安全或不可逆操作，必须作为完整发布的必测项：

- 创建账户。
- 忘记密码后恢复账户。
- 使用助记词导入账户。
- 备份和删除本地账户。
- 绑定、解绑和重新绑定 OOD。
- 覆盖升级并保留用户数据。

## 3. 启动与日常使用

### E2E-01 全新状态启动

用户在没有本地账户的设备上首次启动 App。

要求：

- App 进入欢迎页。
- 用户可以选择创建账户或导入账户。
- 不展示上一次安装或其他用户遗留的身份、设置和 OOD 状态。
- 关闭并重新打开 App 后仍停留在正确的初始状态。

### E2E-02 已有账户启动

用户已经拥有本地账户，并设置了当前身份。

要求：

- App 直接进入主界面，不重复进入欢迎或创建流程。
- 首页展示正确的当前身份。
- 首页展示当前身份对应的 OOD 状态。
- 身份名称在首页、身份列表、设置页和授权页面中保持一致。
- App 重启后仍使用上次确认的身份。

### E2E-03 状态未知和服务不可用

用户启动 App 时，账户或 OOD 的远端状态暂时无法取得。

要求：

- App 不得把“暂时无法取得状态”显示为“账户不存在”或“OOD 未绑定”。
- 用户能够分辨未配置、不存在、暂时不可达和状态未知。
- App 保留上一次已确认状态，或明确显示正在刷新。
- 服务恢复后用户可以重试并得到最新结果。

## 4. 创建账户

### E2E-04 创建新账户

完整路径：

```text
欢迎页 → 创建账户 → 生成助记词 → 备份助记词 → 确认助记词
→ 设置账户名称和密码 → 完成账户注册 → 核对创建结果 → 进入主页
```

要求：

- 用户能够理解账户身份、账户名称和助记词的用途。
- 助记词必须完整展示，并明确提示离线备份和丢失风险。
- 用户未正确确认助记词前不能继续创建。
- 账户名称、密码和准入信息输入不合法时不能提交。
- 账户名称不可用或准入信息无效时，用户可以修改后重试。
- 创建提交后应显示明确进度，不能让用户误以为已经完成。
- 创建失败或中途取消时，不留下可误用的半成品本地账户。
- 创建成功后展示账户名称和身份信息。
- 新账户自动成为当前身份，并进入 OOD 激活入口。
- App 重启后仍能进入该账户。
- 助记词、密码和准入信息不得出现在非必要页面或可分享结果中。

## 5. 导入与恢复账户

### E2E-05 使用助记词导入账户

完整路径：

```text
欢迎页 → 导入账户 → 输入助记词 → 设置新的本地密码
→ 找回原账户 → 进入主页 → 核对原 OOD 状态 → 重启复核
```

要求：

- 用户不需要重新输入原账户名称或重新完成账户注册。
- 助记词错误、单词不完整或无法匹配有效账户时明确失败。
- 导入失败时不创建错误的本地身份。
- 导入成功后恢复原来的同一身份，不创建新的 DID。
- 原账户名称能够自动恢复。
- 导入时设置的新密码用于此设备后续的本地敏感操作。
- 原有 OOD 绑定状态能够从权威状态恢复。
- 导入成功的身份自动成为当前身份。
- App 重启后账户和 OOD 状态保持正确。

### E2E-06 忘记本地密码后恢复

完整路径：

```text
密码验证失败 → 进入忘记密码/恢复身份 → 阅读恢复说明
→ 使用助记词验证身份 → 设置新本地密码 → 返回原目标并完成操作
```

要求：

- 密码输入页面提供可发现的忘记密码或恢复身份入口。
- 明确说明本地密码不能通过账户名称、验证码或服务端找回。
- 明确说明没有助记词将无法恢复身份。
- 使用正确助记词后恢复原来的同一身份。
- 恢复过程不创建第二个不同身份。
- 原账户名称、公开资料和 OOD 绑定状态保持不变。
- 旧本地密码不再可用，新密码可以完成备份、切换和签名操作。

### E2E-07 备份、删除并再次恢复

完整路径：

```text
当前账户 → 输入密码 → 查看并确认助记词 → 删除账户时先取消
→ 再次确认删除 → 返回欢迎页或剩余身份 → 使用助记词恢复
```

要求：

- 未通过密码确认时不能展示助记词。
- 助记词展示后需要用户再次确认已完成备份。
- 删除前明确说明删除范围和恢复条件。
- 取消删除不改变任何账户或 OOD 状态。
- 删除只清除当前设备上的本地账户。
- 删除本地账户不注销远端账户、不解除 OOD 绑定，也不让助记词失效。
- 删除最后一个本地账户后回到欢迎页。
- 仍有其他账户时，进入可继续使用的身份状态。
- 再次导入后恢复原来的身份和 OOD 状态。

## 6. 多身份管理

### E2E-08 添加和切换身份

完整路径：

```text
当前身份 → 添加第二身份 → 查看身份列表 → 选择另一身份
→ 输入对应密码 → 核对首页、OOD 状态和授权身份 → 重启复核
```

要求：

- 身份列表明确标识当前身份。
- 用户可以通过创建或导入添加身份。
- 密码错误或取消时不切换身份。
- 切换成功后，首页、OOD 状态、备份入口和授权页面同时使用新身份。
- 不展示上一个身份的账户名称、OOD 状态或授权结果。
- 重启后保持最后确认的身份。
- 删除当前身份后，剩余身份仍可继续使用。

## 7. OOD 生命周期

### E2E-09 未绑定状态

要求：

- 首页明确显示当前身份尚未绑定 OOD。
- 提供扫描本地 OOD 和访问远程 OOD 两种入口。
- 未绑定状态不会因为历史缓存或其他身份的绑定关系而显示为已绑定。

### E2E-10 扫描并绑定本地 OOD

完整路径：

```text
未绑定状态 → 扫描本地网络 → 识别目标 OOD → 进入激活向导
→ 完成必要配置 → 使用当前身份授权 → 等待激活完成 → 返回 App
→ 重启 App 和 OOD 后复核
```

要求：

- 只展示可识别且能够继续激活的 OOD。
- 用户可以通过名称、地址和设备信息识别目标 OOD。
- 不可访问或返回无效信息的设备不能进入成功状态。
- 激活向导使用的身份必须与 App 当前身份一致。
- 必要配置没有完成时不能将 OOD 标记为已绑定。
- 用户取消或激活失败时仍显示未绑定，并可以重新进入。
- 只有权威状态确认后，App 才显示已绑定。
- App 和 OOD 重启后仍显示正确的绑定关系。

### E2E-11 通过远程地址绑定 OOD

完整路径：

```text
未绑定状态 → 选择远程 OOD → 输入协议、地址和可选端口
→ 验证目标 OOD → 进入激活向导 → 完成绑定 → 返回 App
```

要求：

- 支持用户输入域名、IPv4 和可选端口。
- 地址为空、格式错误、端口非法或包含不支持的路径时阻止继续。
- 目标不可访问、不是有效 OOD 或缺少激活入口时明确提示错误。
- 失败后保留输入界面，允许用户修改地址并重试。
- 远程绑定成功后的状态要求与本地扫描绑定一致。

### E2E-12 已绑定状态和持久化

要求：

- 首页明确显示当前身份已绑定 OOD。
- 用户切换身份后，绑定状态随身份切换。
- 用户删除并重新导入账户后，绑定状态可以恢复。
- App 重启、升级或暂时离线时，不因本地缓存丢失而错误显示未绑定。
- OOD 暂时不可访问时，应区分“已绑定但不可达”和“未绑定”。

### E2E-13 解绑并重新绑定 OOD

完整路径：

```text
已绑定状态 → 选择解绑 → 取消一次并复核状态
→ 再次解绑并确认 → 等待权威状态确认 → 显示未绑定
→ 重启 App 复核 → 恢复同一 OOD → 再次绑定 → 最终重启复核
```

要求：

- 解绑前明确说明影响范围，并让用户核对目标 OOD。
- 取消解绑不改变任何状态。
- 认证失败、网络失败或结果尚未确认时，不能提前显示未绑定。
- 解绑成功只解除当前身份与指定 OOD 的关系。
- 解绑不删除本地账户，也不隐式重置 OOD 数据。
- 存在多个绑定时，目标之外的绑定关系不受影响。
- App 重启后仍保持未绑定状态。
- 同一 OOD 恢复到可绑定状态后，可以再次完成绑定。
- 重新绑定后，App 和 OOD 重启均能恢复最终状态。

## 8. 应用与网页授权

### E2E-14 查看应用列表

要求：

- 用户可以从已绑定状态进入应用页。
- 应用页展示当前可用应用的名称、说明和图标或占位图。
- 应用数据为空或读取失败时提供明确状态。
- 当前版本只要求查看应用列表，不要求安装、启动、升级或卸载应用。

### E2E-15 使用当前身份完成网页授权

完整路径：

```text
App 打开网页 → 网页读取当前身份 → 网页发起签名
→ 用户核对请求 → 输入当前身份密码 → 返回签名结果 → 关闭网页返回 App
```

要求：

- 网页获得的身份与 App 当前身份一致。
- 用户确认前不能产生签名结果。
- 密码错误时允许重试，不改变其他状态。
- 用户取消时返回取消结果，不产生签名。
- 同一时间只处理一个需要用户确认的签名请求。
- 重复请求不会打开多个相互覆盖的密码确认流程。
- 关闭网页后，App 原来的页面和状态保持。
- 切换身份后再次授权，必须使用新身份。

## 9. 设置与平台体验

### E2E-16 语言和主题

要求：

- 用户可以切换受支持语言和浅色、深色主题。
- 修改立即作用于当前页面和后续页面。
- App 重启后保持用户最后选择。
- 主要页面在不同语言下不出现关键信息截断或按钮不可用。

### E2E-17 移动端输入和系统区域

要求：

- 页面内容不被状态栏、底部手势区域或三键导航遮挡。
- 创建、导入、绑定和密码弹窗中的输入框不被键盘遮挡。
- 键盘弹出后用户仍能看到当前输入、错误提示和提交按钮。
- 返回键或关闭键盘不会意外退出或提交当前流程。
- App 内承载的网页在移动端保持可阅读、可滚动和可返回。

### E2E-18 桌面端窗口和单例

要求：

- Windows 和 macOS 重复启动 App 时只保留一个主实例和一个主窗口。
- 从 App 打开的同一业务网页应复用已有窗口并获得焦点。
- 打开网页不替换主窗口当前页面。
- 关闭子窗口不退出主 App。
- 多窗口之间显示的当前身份保持一致。

## 10. 安装与升级

### E2E-19 全新安装

完整路径：

```text
安装 App → 首次启动 → 进入欢迎页 → 创建或导入账户
→ 进入主页 → 关闭并重新启动
```

要求：

- 安装完成后 App 可以正常启动。
- 全新安装不继承其他安装留下的本地账户和设置。
- 创建和导入入口可用。
- 完成账户流程后，App 重启仍能正常使用。
- macOS 组合安装包中的 App 和 OOD 都应具备各自可见的正常状态。

### E2E-20 覆盖升级

完整路径：

```text
旧版本准备已有账户、当前身份、设置和 OOD 状态
→ 覆盖升级 → 启动新版本 → 核对状态 → 完成一次身份授权 → 再次重启
```

要求：

- 升级前必须记录原版本，升级后能够确认当前版本已经更新。
- 本地账户、当前身份、语言、主题和必要设置保持。
- OOD 绑定状态保持，并能从权威状态刷新。
- 旧数据需要迁移时，不要求用户重新创建账户。
- 迁移失败时不能破坏原账户数据或伪造成功状态。
- 升级后备份、切换身份和签名仍可使用。
- Windows 和 macOS 升级后仍满足 App 单例要求。

## 11. 失败、取消与重试

以下要求适用于创建、导入、切换身份、备份、删除、绑定、解绑和签名流程：

- 用户取消后返回可理解的上一步，且不产生副作用。
- 输入错误时指出具体问题，并允许用户修正。
- 网络中断或服务超时时，明确显示操作未确认。
- 未取得最终结果前不能显示成功。
- 用户重复点击不会重复创建账户、重复绑定或重复执行不可逆操作。
- 失败后用户可以从安全状态重试，不需要通过清除 App 数据恢复。
- App 在操作过程中退出后，重新启动时不能显示错误的完成状态。

## 12. 安全与隐私

- 助记词只在创建、备份和恢复所必需的页面显示。
- 查看助记词前必须完成当前身份的密码确认。
- 密码不得明文回显或保存在可见页面。
- 删除、解绑和签名必须经过明确的用户确认。
- 不同身份的账户信息、OOD 状态和签名结果必须隔离。
- 截图、分享结果和错误信息不得包含完整助记词、密码、私钥、准入信息或完整授权凭据。
- 用户拒绝授权后，不得继续执行原请求。

## 13. 完整路径组合

### 路径 A：新用户首次使用

```text
全新安装 → 创建账户 → 首次绑定 OOD → 重启 App
→ 查看当前身份和 OOD 状态 → 查看应用 → 完成一次网页授权
```

覆盖：E2E-01、E2E-04、E2E-10、E2E-12、E2E-14、E2E-15、E2E-19。

### 路径 B：账户恢复

```text
备份身份 → 取消删除 → 删除本地账户 → 使用助记词导入
→ 恢复原 OOD 状态 → 完成一次密码操作 → 重启 App
```

覆盖：E2E-05、E2E-07、E2E-12、E2E-15。

### 路径 C：忘记密码

```text
密码验证失败 → 进入恢复入口 → 使用助记词恢复同一身份
→ 设置新密码 → 完成原操作 → 重启 App
```

覆盖：E2E-06、E2E-15。

### 路径 D：OOD 完整生命周期

```text
未绑定 → 绑定 OOD → 重启确认 → 取消解绑 → 成功解绑
→ 重启确认 → 恢复同一 OOD → 重新绑定 → App/OOD 重启确认
```

覆盖：E2E-09、E2E-10 或 E2E-11、E2E-12、E2E-13。

### 路径 E：多身份隔离

```text
准备两个身份 → 切换身份 → 核对首页、OOD 和授权身份
→ 切回原身份 → 删除当前身份 → 核对剩余身份 → 重启 App
```

覆盖：E2E-02、E2E-08、E2E-12、E2E-15。

### 路径 F：覆盖升级

```text
旧版本准备日常状态 → 覆盖升级 → 核对身份、设置和 OOD 状态
→ 完成一次网页授权 → 重启 App
```

覆盖：E2E-02、E2E-12、E2E-15、E2E-16、E2E-18、E2E-20。
